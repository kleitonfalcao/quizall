# 🚩 Quiz das Bandeiras do Mundo

Um aplicativo web interativo, divertido e educativo criado especialmente para smartphones, para testar conhecimentos sobre bandeiras de todos os países do mundo!

## 🌟 Principais Recursos

- 🚩 **Bandeiras de Todos os Países**: Imagens em alta definição via SVG da FlagCDN.
- 🎯 **Opções Inteligentes**: O jogo seleciona alternativas parecidas (ex: Romênia vs Chade, Holanda vs Luxemburgo) para um desafio empolgante!
- ⏱️ **Cronômetro de 15 Segundos**: Contagem regressiva interativa com alertas visuais e sonoros nos últimos 5 segundos.
- 💡 **Ajudas do Jogo do Milhão**:
  - **50:50**: Elimina duas alternativas erradas.
  - **Dica**: Revela o continente e curiosidades sobre o país.
  - **Pular**: Passa para a próxima bandeira sem perder pontos.
- 🎵 **Áudio Sintetizado (Web Audio API)**: Música de suspense ao fundo, sons táticos, arpejo de acerto e efeito grave de erro — sem dependência de arquivos externos!
- 🏆 **Micro-Vitórias & Confetes**: Frases motivadoras e chuva de confete a cada conquista.
- 📱 **Mobile-First**: Design amigável, cores alegres e botões grandes perfeitamente ajustados para celular.

## 🚀 Como Publicar Grátis no GitHub Pages (Passo a Passo em 2 minutos)

1. **Crie uma conta ou entre no GitHub**:
   - Acesse [github.com](https://github.com) e faça login.

2. **Crie um Novo Repositório**:
   - Clique no botão **+** (canto superior direito) → **New repository**.
   - Dê um nome ao repositório (exemplo: `quiz-bandeiras`).
   - Mantenha a opção **Public** marcada e marque a opção **Add a README file**.
   - Clique em **Create repository**.

3. **Envie os Arquivos do Jogo**:
   - No repositório criado, clique em **Add file** → **Upload files**.
   - Arraste todos os arquivos da pasta do projeto (`index.html`, `styles.css`, `README.md`, `QuizzBandeiras.md` e a pasta `js/` inteira).
   - Clique no botão verde **Commit changes**.

4. **Ative o GitHub Pages**:
   - No seu repositório, clique na aba **Settings** (Configurações).
   - No menu lateral esquerdo, clique em **Pages**.
   - Em **Build and deployment** -> **Branch**, selecione `main` (ou `master`) e `/ (root)`.
   - Clique em **Save**.

5. **Pronto! 🎉**:
   - Em cerca de 1 a 2 minutos, o GitHub vai gerar o seu link oficial (exemplo: `https://seu-usuario.github.io/quiz-bandeiras/`).
   - Abra esse link no celular do seu filho ou salve o atalho na tela inicial do smartphone!
